# 微信公域流量适配方案

## 1. 概述

本文档为诺派永生花微信小程序制定公域流量获取方案，覆盖视频号、搜一搜、公众号、朋友圈广告四大渠道，旨在降低获客成本，提升小程序曝光与用户增长。

---

## 2. 视频号挂载小程序方案

### 2.1 视频号主页挂载

**设置路径**：视频号创作者中心 → 商品橱窗 → 挂载小程序

**配置要点**：
- 将诺派永生花小程序挂载到视频号主页「商品橱窗」位置
- 选择 3-5 款爆款/主推商品展示在橱窗首位
- 橱窗商品标题需包含核心关键词（如「永生花」「不凋谢」「送女友」「客厅摆件」）

**素材建议**：
| 内容类型 | 建议主题 | 时长 | 挂载方式 |
|---------|---------|------|---------|
| 产品展示 | 永生花开箱/实拍展示 | 15-30s | 商品链接 |
| 场景种草 | 客厅/玄关永生花摆件搭配 | 30-60s | 商品链接 |
| 教程类 | 永生花保养/搭配技巧 | 30-60s | 小程序主页 |
| 情感类 | 送礼情感故事/纪念日 | 15-30s | 商品链接 |
| 活动类 | 限时优惠/节日促销 | 15s | 商品链接 |

### 2.2 视频号直播挂载

**前提条件**：
- 完成微信小店入驻（已完成）
- 视频号绑定小程序（需在微信公众平台配置）
- 商品同步至微信小店

**实现步骤**：
1. 微信公众平台 → 功能 → 微信小店 → 商品管理
2. 将小程序商品同步到视频号商品库
3. 直播时在小黄车添加商品链接
4. 配置直播专属优惠券（直播间领券链接）

**技术配置**：
```javascript
// 小程序侧：处理视频号跳转参数（app.js onShow）
onShow(options) {
  // 视频号场景值为 1089
  if (options.scene === 1089) {
    console.log('来自视频号流量', options.query)
    
    // 解析视频号传递的推广参数
    const { promo_id, goods_id } = options.query || {}
    
    // 记录渠道来源
    app.globalData.channelSource = 'weixin_video_channel'
    
    // 追踪视频号引流事件
    app.trackEvent('traffic_video_channel', {
      promo_id,
      goods_id
    })
    
    // 如有指定商品ID，直接跳转
    if (goods_id) {
      wx.navigateTo({
        url: `/pages/product/detail?id=${goods_id}`
      })
    }
  }
}
```

### 2.3 视频号内容运营节奏

| 频率 | 内容方向 | 目的 |
|------|---------|------|
| 每周 3-5 条 | 产品展示 + 场景种草 | 日常曝光 |
| 每周 1-2 场 | 主题直播（搭配/教程/花艺） | 即时转化 |
| 节日前 1-2 周 | 节日礼品推荐系列 | 节日流量 |
| 每月 1 次 | 用户问答/互动合集 | 提升粉丝粘性 |

## 3. 搜一搜搜索优化

### 3.1 小程序搜索接入

**前置条件**（已满足）：
- 小程序已发布上线 ✅
- 服务类目完整填报 ✅
- 小程序名称包含核心关键词「诺派永生花」

### 3.2 搜索关键词优化策略

**核心关键词**：
| 关键词类型 | 示例 | 优化策略 |
|-----------|------|---------|
| 品牌词 | 诺派永生花、诺派 | 确保品牌词搜索排名 |
| 品类词 | 永生花、保鲜花、干花、仿真花 | 标题/描述中包含 |
| 场景词 | 生日礼物、结婚礼物、送女友、送妈妈 | 页面标签中覆盖 |
| 功能词 | 客厅摆件、玄关装饰、婚庆花艺 | 商品详情页覆盖 |

**站内SEO优化**：
```json

      "诺派", "诺派永生花"
```

**页面标题优化**：
- 首页标题: `诺派永生花 | 高品质永生花礼物 客厅摆件 不凋谢`
- 商品页标题: `{商品名称} | 诺派永生花 - 精选{品类}礼物`
- 分类页标题: `{分类名称} - 诺派永生花网上商城`
- 活动页标题: `{活动名称} | 诺派永生花 限时优惠`

### 3.3 搜索结果展示优化

**封面图要求**：
- 主图比例：1:1 正方形（最佳）
- 最少 3 张不同角度的商品图
- 图片质量 >600px，背景纯净
- 主图中文字不超过图面积的 30%

**描述优化**：
- 商品描述包含 3-5 个核心关键词
- 突出价格优势（如「限时 7 折」「包邮」）
- 突出服务承诺（如「30 天包退」）
- 标注品牌标识

### 3.4 小程序页面收录优化

- 核心页面（首页、分类页、活动页）确保被微信索引收录
- 使用 `<meta-data>` 标签在 WXML 中添加页面描述
- 确保页面加载速度 < 3 秒（影响搜索权重）
- 保持每周至少更新一次首页/活动内容

## 4. 公众号图文引流

### 4.1 公众号配置

**前提条件**：
- 绑定同一微信开放平台下的公众号
- 在公众号菜单配置小程序入口
- 在公众号资料页展示小程序

### 4.2 图文内容策略

| 内容类型 | 配文方向 | 小程序插入方式 | 发布频率 |
|---------|---------|---------------|---------|
| 产品种草 | 永生花客厅搭配方案 | 文中小程序卡片 | 每周 2 篇 |
| 礼品推荐 | 节日送礼指南（七夕/母亲节/春节） | 文中商品卡片 | 节日前 2 周 |
| 花艺知识 | 永生花养护/花期区别 | 文末小程序入口 | 每周 1 篇 |
| 用户故事 | 买家秀/送礼故事 | 文中小程序卡片 | 每月 2 篇 |
| 活动推广 | 限时特惠/新品上线 | 文中卡片 + 阅读原文 | 每月 4 篇 |

### 4.3 图文嵌入小程序方式

**方式一：小程序卡片（推荐）**
```html
<!-- 公众号编辑器中嵌入小程序卡片 -->
<mp-miniprogram 
  path="pages/product/detail?id=prod_001" 
  title="永生花客厅摆件 - 限时7折"

  appid="wx7f092564e7a079a6"
>
  <button>立即购买</button>
</mp-miniprogram>
```

**方式二：文字超链**
```
<a data-miniprogram-appid="wx7f092564e7a079a6" data-miniprogram-path="pages/index/index" href="">点我进入诺派永生花商城</a>
```

**方式三：阅读原文**
```
在图文底部设置「阅读原文」跳转到小程序活动页
```

**方式四：公众号菜单**
```
公众号菜单 → 三个自定义菜单：
1. 「进入商城」→ 打开小程序首页
2. 「最新活动」→ 打开小程序活动页
3. 「联系客服」→ 打开客服会话
```

| 小程序推广 | 用户增长 | 800元/天 | 小程序拉起 |

### 5.2 广告投放策略

**定向设置**：
